## Проверенная среда

25.09.2026 дополнительно устранены три подтверждённых проблемы:
рабочий inference не применял единый лимит потоков всех ML-библиотек;
публичный CI-образ MinIO перестал скачиваться; frontend runtime содержал
`libexpat`, для которого появился security fix. Исправления и результаты:
[проверки 25 сентября](production-readiness.md#проверено-25-сентября).
Новый сквозной CI проверил настоящие HTTP upload, YOLO, S3, CSV и восстановленный API.

Backend проверяется на закреплённых зависимостях из `backend/requirements.txt`.
Для настоящих SQL-тестов поднят отдельный локальный PostgreSQL с 32 MiB shared
buffers, портом 55439 и временными схемами. Контейнеры не запускались.
Проверено обновление заполненной схемы `0005` с сохранением старых снимков и
ожидаемой численности из существующей записи посещаемости.

Отдельный тест выполняет `pg_dump` и `pg_restore` в новую временную БД.
Он не проверяет S3 и не является доказательством восстановления всего стенда.

## Незакрытые границы

- Корректность счётчика людей в реальных аудиториях требует размеченной выборки.
  Уверенность детектора не доказывает точность подсчёта.
- SHA-256 имеющихся весов фиксирует байты, но не устанавливает права на их распространение.
- Сеть камер, TLS реального домена, S3 retention и внешнее хранилище копий требуют
  отдельного эксплуатационного стенда. CI restore не подтверждает его настройки.
- Старая история не содержит полных снимков всех полей расписания и ролей камер.
  Утраченные исторические значения невозможно достоверно восстановить миграцией.

Итоговые команды и статусы приведены в [матрице готовности](production-readiness.md).
