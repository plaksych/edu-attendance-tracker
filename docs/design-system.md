# Интерфейс

Рабочее приложение использует светлую тему и компактную навигацию. Режим показа
открывает те же страницы и данные, скрывая второстепенные элементы. Отдельной
версии результатов для презентации нет.

## Где Менять Оформление

- `frontend/src/index.css`: базовые поля, кнопки, таблицы, сетка и статусы.
- `frontend/src/production.css`: итоговая палитра, типографика, компоновка,
  focus и режим показа; подключается после `index.css`.
- `frontend/src/components/`: навигация, диалоги, показатели, происхождение
  результатов и история распознавания.
- `frontend/src/main.tsx`: подключение локальных шрифтов и порядок стилей.

Focus: контур `3px solid #2869bc` с отступом `3px`. Статус и происхождение
результата всегда подписаны: цвет не заменяет текст.

Боковая панель занимает 240px. Максимальная ширина контента 1536px,
в режиме показа 1360px. Основной ряд отступов: 8/12/16/24/32/48px.
Высота управляющих элементов не менее 44px. Широкие таблицы прокручиваются
внутри своей области, а не расширяют страницу.

## Шрифты И Изображения

Основной шрифт: Golos Text Variable, 15px, межстрочный интервал 1.5.
Заголовки и показатели: Onest Variable. H1: 30px/650, на узком экране 26px;
H2: 19px/600, на узком экране 18px. Числовой показатель: 34px, на мобильном 28px.
Табличные данные: 14px. Числа используют `tabular-nums`, letter-spacing равен 0.

WOFF2 поставляются пакетами `@fontsource-variable/golos-text` и
`@fontsource-variable/onest`; версии закреплены lockfile. Обращений к Google Fonts
во время работы нет. Лицензии OFL находятся в `frontend/public/licenses/`.
Используется существующий набор контурных иконок проекта.

`frontend/public/synthetic-classroom.png` создаётся скриптом
`frontend/scripts/create-demo-asset.mjs`: это схема с 18 маркерами, **не результат
распознавания фотографии**. Учебные имена и группы синтетические, дата примера
фиксирована: 2026-09-23. Fixture и схема исключаются из production-сборки.

## Поведение

| Состояние | Что видит пользователь |
| --- | --- |
| Загрузка | Фактический этап; повторная отправка заблокирована |
| Ошибка | Причину, действие для повтора и request ID при наличии; сообщения доступны через `role="alert"` |
| Пустой список | Отсутствие записей либо совпадений с фильтром |
| Нет замера | Пропуск в графике и неполный итог, не нулевую посещаемость |
| Истекла сессия | Вход с сохранением исходного маршрута |
| Нет прав | Недоступное действие и серверный отказ; скрытие кнопки не заменяет авторизацию |
| Распознавание | Кадр целиком, масштабирование, отдельную историю попыток и корректировок, источник результата |
| Аналитика | Группу, период, полноту замеров, таблицу графика и экспорт; значения выше 100% не обрезаются |
| Сервер | Ответ API по БД, хранилищу, очереди и heartbeat; непроверенный backup так и подписан |

Карточки полноты считают **занятия**, а не отдельные кадры или замеры.
Диалоги и мобильное меню удерживают focus, закрываются Escape и возвращают
focus к исходной кнопке. Фильтры занятий и аналитики сохраняются в URL.

## Режим Показа

Администратору доступна последовательность: обзор → распознавание → занятие
выбранного дня → аналитика его группы. Занятие берётся через API и сортируется
по началу/ID; жёстко заданного ID в live-режиме нет. При пустом дне открывается
список без записей, при ошибке загрузки показ не запускается.

«Назад» и «Далее» переключают этапы. «Выйти из показа» и Escape оставляют текущую
страницу, «Вернуться к работе» восстанавливает исходный маршрут и фильтры.
Полный экран включается отдельной кнопкой; отказ браузера не прерывает показ.
Метка учебного примера, происхождение результата и ошибки остаются видимыми.
Самостоятельный пример с 18 маркерами не выдаётся за источник замера занятия.

Целевой сценарий занимает 90–120 секунд: обзор, источник числа, полнота занятия,
аналитика и экспорт. Это длительность рассказа, не обещание скорости inference.

## Адаптивность И Проверка

Основные breakpoints: 1180, 900 и 680px. Ниже 900px меню становится выдвижным,
инспектор распознавания располагается под списком. Ниже 680px поля переносятся,
показатели остаются в двух колонках, диалоги ограничиваются viewport.
`prefers-reduced-motion` отключает необязательные переходы и плавную прокрутку.

Из `frontend` выполнить `npm run test:e2e`. Проверяются 320, 360, 390, 768,
1280, 1440 и 1920px, клавиатура/focus, переполнение, загрузка изображений,
запрет API-запросов fixture, навигация показа и axe на основных сценариях.
Chromium/Firefox/WebKit не заменяют настоящий iPhone, screen reader и ручную
проверку масштаба 200%. Полное соответствие WCAG не заявлено.
