05 / Режимы работы

Где выполняется обработка

В браузере

Свой файл на устройстве

Файл → ONNX / WASM → Результат
Без загрузки на сервер

На сервере

Полный рабочий контур

API → Очередь → YOLO worker
История и общие данные

С камер

Опциональный профиль

RTSP → FFmpeg → S3 + очередь
Не нужен для своих файлов

Статическое демо показывает интерфейс. Оно не заменяет серверный стенд.
